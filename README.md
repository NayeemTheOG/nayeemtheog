## Overview

This repository powers my personal site, a living archive that documents my ongoing work across analytical finance, mathematics, quantitative research, and software engineering. It functions as a portfolio, a research journal, and a long-term record of professional development, all built on a modern, performance-focused frontend.

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Hosting | Vercel |
| Version Control | GitHub |

## Features

- Modern, modular portfolio architecture
- Dedicated showcase for quantitative finance projects
- Research and writing archive
- Fully responsive interface across devices
- Performance-optimized frontend
- Structured for long-term scalability

## Getting Started

Clone the repository and install dependencies to run the project locally.

```bash
git clone https://github.com/NayeemTheOG/nayeemtheog.git
cd nayeemtheog
npm install
npm run dev
```

The site will be available at `http://localhost:3000`.
